# Evidence

This folder stores test and runtime evidence generated from the development loop.

## GitHub Actions

GitHub Actions validates unit tests, Python compilation, container build, offline GraphRAG smoke tests, and evidence layout. Workflow logs remain in GitHub Actions.

## GCP Cloud Shell

Cloud Shell runs the same repository code against the real GCP development context. Evidence generated by `make cloud-evidence` is written under `docs/evidence/generated/YYYYMMDDTHHMMSSZ/` and should be committed to the same branch that produced it.

## Rule

> Evidence must reference the exact Git commit it validates.

A PR should therefore contain both implementation code and proof that the implementation was tested in the intended GCP environment.
